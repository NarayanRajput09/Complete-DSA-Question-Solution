## 📌 Overview

This repository is designed to help beginners and intermediate developers master Data Structures & Algorithms from the ground up:
- **Core Basics:** Java syntax, condition statements, loops, and pattern printing.
- **Linear Data Structures:** Arrays, ArrayLists, Linked Lists, Stacks, and Queues.
- **Non-Linear Data Structures:** Binary Trees, Binary Search Trees (BST).
- **Core Algorithms:** Sorting, Searching, Matrix operations, Recursion, and String manipulation.
- **Problem Solving:** LeetCode and standard interview questions with clear implementations.

## 🚀 How to Run Locally

### Prerequisites
Make sure you have **Java (JDK 8 or higher)** installed on your machine.

To check your Java version:
```bash
java -version
```

### Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/NarayanRajput09/Complete-DSA-Question-Solution.git
   cd Complete-DSA-Question-Solution
   ```

2. **Compile any Java File:**
   ```bash
   javac Array/TwoSum.java
   ```

3. **Run the Program:**
   ```bash
   java Array.TwoSum
   ```
